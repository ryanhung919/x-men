# Issue tracker: Local Markdown

- One feature per directory: `.scratch/<feature-slug>/`.
- Specifications live at `spec.md` within that directory.
- Implementation tickets live at `issues/<NN>-<slug>.md`, numbered from 01, with one file per ticket.
- Record triage state using a `Status:` line near the top; use the vocabulary in `triage-labels.md`.
- Append discussion under `## Comments`.
- Publishing means creating or updating the appropriate local file.
- Fetching a ticket means reading its referenced local file.
